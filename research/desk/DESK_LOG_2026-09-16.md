## R1 (D-2 item 1b) — how to capture player_streaming in a -game process tonight

**Question.** Item 1b prescribes "player_streaming as MRQ in a -game process per
Epic's command-line rendering doc, one capture at vista, HLOD-proxy fraction."
On this machine tonight the DDC is cold (a fresh -game process must recompile
shaders — the editor's first load took ~15 min), the -game MRQ executor path is
untested here, and a depth pass in -game is unverified. Options: A) full
MRQ-in-game (Queue asset + `-MoviePipelineConfig`, multilayer EXR, depth>512 m
proxy fraction); B) -game HighResShot positioned via `-ExecCmds` (like
perf_standalone), proxy band by frame-diff vs the editor_player force-loaded
frame; C) a runtime-module scene-capture (heavy, R-GAMEPLAY).

**Reasoning.** The deliverable is a GEOMETRY question — does the landscape HLOD
proxy render in the real runtime, and what pixel fraction. Proxy geometry is
instrument-independent, so it does NOT need MRQ's temporal-8 / cvar config to be
answered; the desk's own method ("derive, read back, RECORD BOTH SIDES") is
satisfied by comparing a -game frame to the editor_player force-loaded frame —
the pixels whose geometry differs ARE the proxy band. Option A is the durable,
doc-matching instrument and has value beyond tonight (a real runtime look/perf
capture), but building it robustly against a cold DDC and an untested -game MRQ
path risks eating hours of the overnight window for a geometry answer B gives
cheaply. C is overkill (a runtime module for one frame). R-RANGE 512 m and
R-HLODTEX (handoff §3) define the band: real surface to 512 m, HLOD proxy beyond.

**Decision.** Attempt **A first, hard-time-boxed to 25 minutes** from -game
launch: abort if no output frame has landed on disk by 25 min, or if at 25 min
shader-compile is still saturated with zero render progress in the log. On abort
or any A failure, fall back to **B**: one -game HighResShot at vista (camera
positioned via -ExecCmds, after the same warm-up perf_standalone uses), and
measure the proxy fraction by frame-diff of the -game frame against the
editor_player force-loaded vista frame (report the pixel sample count, rule 13).
EITHER path delivers the -game proxy fraction with both sides recorded. COMMIT
the A scaffolding (the saved Queue asset + the -game driver) even if A aborts, so
it is a named starting point, not re-derived. If BOTH A and B fail to launch
-game at all, PARK 1b, log the -game launch log as evidence, and spawn again for
a new ruling — do not fake a number. Cite: MovieRenderPipelineCommandLine.cpp
:202-213 (the -game MRQ contract); handoff §3 R-RANGE / R-HLODTEX (the band);
rule 13 (sample count). — deputy, 2026-09-16
